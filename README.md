# Zeldris Tap

## Installation

`brew install zeldrisho/tap/<formula>`

Or `brew tap zeldrisho/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "zeldrisho/tap"
brew "<formula>"
```
